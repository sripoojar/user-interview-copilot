# 🎯 User Interview Copilot

An AI-powered tool that transforms raw user interview transcripts into 
structured PM insights — connecting user voice directly to product 
strategy, metrics, and stakeholder narrative.

🔗 **[Live Demo](https://user-interview-copilot.streamlit.app/)**

---

## The Problem

PMs have tools for every part of their job — Figma for design, 
analytics tools for data — but nothing that connects a user interview 
all the way through to product strategy and metrics in one place. 
The connective tissue is missing.

## What It Does

Paste a raw transcript or bullet point notes from any user interview. 
The tool asks 5 context questions about your product, then produces:

- **Persona Signal** — who this user really is and what drives them
- **Strategic Connection** — how this feedback connects to your product vision
- **Metric Recommendations** — what to measure, including what NOT to track
- **The Stakeholder Story** — a 3-paragraph narrative ready to share with leadership

## Why It's Different

This is not a summariser. It's a "connect the dots" engine. 
The output is tailored to your business model (B2C/B2B), 
product stage, and interview goal — so the insights are 
specific to YOUR product, not generic PM advice.

## Built With

- Python
- Streamlit
- Anthropic Claude API

## How To Run Locally

1. Clone this repo
2. Install dependencies: `pip install streamlit anthropic`
3. Run: `streamlit run app.py`
4. Add your Anthropic API key in the sidebar
